# «Эксперты чистоты» — сайт клининга для Netlify

Готовый сайт с калькулятором стоимости, админкой и заявками в Telegram.
Работает на **бесплатном тарифе Netlify**: без сервера, без базы данных, без установки чего-либо на компьютер.

- Сайт: главная, услуги, цены, калькулятор, контакты.
- Админка `/admin`: цены, услуги, фото, тексты, FAQ, контакты, статусы заявок.
- Заявки приходят владельцу в Telegram, а копия хранится в админке.

## Запуск за 15 минут

### 1. Залить проект на GitHub
1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **New repository**, придумайте имя (например, `chistota`), нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое** папки проекта (файлы и папки `public`, `src`, `netlify`, `content.js`, `package.json`, `netlify.toml` и т. д.). Нажмите **Commit changes**.

### 2. Подключить к Netlify
1. Зайдите на [app.netlify.com](https://app.netlify.com) (можно войти через GitHub).
2. **Add new project → Import an existing project → GitHub** → выберите репозиторий.
3. Ничего не меняйте в настройках сборки, нажмите **Deploy**.

> Перетаскивание папки в Netlify Drop **не подойдёт**: админка и Telegram работают через Netlify Functions, а они подключаются только через GitHub (или Netlify CLI).

### 3. Создать бота для заявок
1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен** вида `123456789:AAH...`.
2. Напишите своему новому боту любое сообщение (иначе он не сможет писать вам).
3. Узнайте свой **chat_id**: напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт число, например `123456789`.
   - Нужно присылать заявки в группу? Добавьте бота в группу, а chat_id группы узнайте через [@getmyid_bot](https://t.me/getmyid_bot) (он начинается с минуса).
   - Несколько получателей — через запятую: `123456789,987654321`.

### 4. Задать три переменные в Netlify
**Project configuration → Environment variables → Add a variable**:

| Имя | Значение |
|---|---|
| `ADMIN_PASSWORD` | пароль для входа в админку, **не короче 10 символов** |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat_id |

Затем **Deploys → Trigger deploy → Deploy site**, чтобы переменные применились.

### 5. Готово
- Откройте `https://ваш-сайт.netlify.app/admin`, войдите с паролем.
- На главной админки нажмите **«Проверить Telegram»** — придёт тестовое сообщение.
- Отправьте тестовую заявку с сайта.

Свой домен: **Domain management → Add a domain** (HTTPS Netlify включит сам).

## Как пользоваться админкой

| Раздел | Что можно |
|---|---|
| Обзор | новые заявки, чек-лист «что ещё заполнить», проверка Telegram |
| Заявки | копии всех заявок, поиск, статусы «новая / в работе / завершена / отменена», заметки |
| Услуги и цены | добавить / изменить / скрыть / удалить услугу, цена за м² или за штуку, минимальный заказ, фото |
| Доп. опции | «Духовка +700 ₽» и т. п. в калькуляторе |
| Тексты и блоки | заголовки главной, фото первого экрана, включить/выключить блоки |
| Вопросы, преимущества, этапы, отзывы | редактирование списков |
| Контакты и соцсети | телефон, email, часы, районы, Telegram/WhatsApp/VK, реквизиты |
| Внешний вид и SEO | цветовая схема, логотип, заголовок для поисковиков, **плашка «Демонстрационный сайт»** |

Изменения появляются на сайте сразу после сохранения (иногда — через минуту, пока обновится кеш).

**Сменить пароль:** поменяйте `ADMIN_PASSWORD` в Netlify и сделайте Redeploy — все старые входы сбросятся.

1. В админке: настоящий телефон, email, реквизиты, цены, фото работ.

## Для разработчика

- Без зависимостей в коде, кроме `@netlify/blobs` и `@netlify/functions` (Netlify ставит их сам при деплое).
- `netlify/functions/site.mjs` — одна функция обслуживает все страницы; статика из `public/` отдаётся напрямую.
- Данные: Netlify Blobs (контент — один JSON, заявки — второй JSON, фото — отдельные ключи).
- `content.js` — стартовое наполнение, используется **только при первом запуске**, дальше всё меняется в админке.
- Безопасность: пароль только в переменной окружения; подписанная HttpOnly-cookie; CSRF-токены; лимит попыток входа; антиспам формы (ловушка, проверка скорости, лимит 5 заявок за 10 минут с IP); проверка типа загружаемых фото по содержимому; строгий CSP.
- Локальный запуск: `ADMIN_PASSWORD=любой-пароль-123 node dev.js` → http://localhost:8888 (данные в `.data/`). Тесты: `node --test test/`.

Иллюстрации в `public/static/img` нарисованы для проекта (свободны в использовании). Шрифты Inter и Lora — лицензия SIL OFL 1.1.
